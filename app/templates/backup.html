Backup

One archive of everything the configurator manages, so a lost disk or a bad day can be undone:

  • the rules, OIDC clients, users, access tests and disabled rules;
  • the full history (the git repository) and the audit log;
  • {% if has_keys %}the OIDC private signing keys (they are not in git, so without them Authelia cannot be restored){% else %}no signing key files: the keys are still in the main configuration (see Keys){% endif %}.
The archive contains password hashes{% if has_keys %} and private keys{% endif %}. Keep it encrypted and off shared drives. The download is recorded in the audit log.

Not included: the main configuration.yml (this tool never reads its secrets). Back it up with your normal host backups.

To restore, stop the configurator, extract it into the Authelia config folder (tar -xzf authelia-managed-....tar.gz -C /path/to/authelia recreates managed/), keep secrets/ at mode 700, and start it again. Back to History.
